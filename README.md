### Objective

Build a practical enterprise-style Splunk environment demonstrating:
- Security telemetry ingestion
- SPL-based detection engineering
- Alert triage
- Security investigation
- Event correlation
- MITRE ATT&CK mapping
- Detection tuning
- SOC dashboards
- MDR incident response workflows
